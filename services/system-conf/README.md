# system-conf

A service that exposes system settings and statistics as a configuration (`Conf`) subtree built with
configlib. The tree is advertised as `system` and can be registered with the service locator as an
`ISERVICELOCATOR_TYPE_CONF` interface or handed to a service exporting configuration trees (eg.
proto-conf).

## Tree layout

```
system
├── firmware
│   ├── version      (string) firmware version               (UMESH_VERSION)
│   ├── port         (string) build target port name         (PORT_NAME)
│   ├── application  (string) application name                (CONFIG_APP_NAME)
│   └── date         (string) build date                     (UMESH_BUILD_DATE)
├── uptime           (u32)    seconds since the scheduler started
├── memory
│   ├── total        (u32)    total RAM region available, bytes
│   ├── static       (u32)    statically allocated RAM (data+bss+noinit), bytes
│   ├── heap         (u32)    configured heap size, bytes
│   └── used         (u32)    currently used heap, bytes
└── reset            (bool)   reads false; write true to reset the device
```

The `firmware` leaves are compile-time constants captured from the build identity available through
`main.h` (`version.h` is generated by the build system). They are flagged read-only.

`uptime` is derived on read from the FreeRTOS tick counter, so no task is needed. NOTE: with a 32-bit
tick (`configUSE_16_BIT_TICKS = 0`) it wraps back to zero every `2^32 / configTICK_RATE_HZ` seconds
(~49.7 days at 1000 Hz); wraps are deliberately not tracked (see the source for the rationale).

The `memory` counters are all in bytes:

| Node     | Source                                                                          |
|----------|---------------------------------------------------------------------------------|
| `total`  | `LENGTH(ram)` from the linker script (`_ram_size`), the RAM available to the FW  |
| `static` | `_ebss - _ram_start`: data + bss + noinit; the heap lives above `_ebss` so it is excluded |
| `heap`   | `configTOTAL_HEAP_SIZE` from the FreeRTOS config                                 |
| `used`   | `configTOTAL_HEAP_SIZE - xPortGetFreeHeapSize()`, computed on read               |

`total`, `static` and `heap` are constants resolved in `init()`; `used` is computed on read. The heap
here is the newlib/`sbrk` allocator (`heap_useNewlib`), which grows from `_ebss` up to
`_ebss + configTOTAL_HEAP_SIZE`.

## Usage

```c
SystemConf system_conf;
system_conf_init(&system_conf);

Conf *root = NULL;
system_conf_get_conf(&system_conf, &root);
iservicelocator_add(locator, ISERVICELOCATOR_TYPE_CONF, (Interface *)root, "system");
```
